Features

  • Peer-to-peer file transfer: Transfer files directly between devices without going through a central server.
  • Optical QR Pairing: Easily pair devices by scanning a QR code.
  • Zero-cloud End-to-End Encryption: All transfers are encrypted end-to-end, ensuring your data remains private and secure.
  • LAN & Global Relay Fallback: Transfers occur over the local network when possible, with a global relay fallback for cross-network connections.

Installation

To install the Beam CLI, download the binary from the latest release on our GitHub page and add it to your PATH.

Alternatively, you can build from source using Go:

go install github.com/beamshare/beam/cmd/beam@latest

Security Architecture

Beamshare uses WebRTC for peer-to-peer connections. Data channels are encrypted end-to-end using DTLS (Datagram Transport Layer Security). Our relay server only facilitates connection signaling and does not have access to the transferred data.
