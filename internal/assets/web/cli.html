Receiver Docs CLI Guide

Sending Files

Use the beam send command to share a file.

beam send /path/to/your/file.txt

This will generate a short phrase (e.g. "brave-eagle") and a QR code. The receiver can enter the phrase on another CLI or scan the QR code with their mobile device on the receiver website.

Receiving Files

Use the beam receive command to download a file sent by another user.

beam receive brave-eagle

Live Pipe

You can pipe data directly into Beam to share it live over the network.

tar cvz . | beam send

On the receiving end, you can pipe the output directly to another command:

beam receive brave-eagle | tar xvz
